# Learn

This folder is one topic the user is learning, worked on by a group of Claude
sessions. Every thread in the group runs here and shares these files, so read
what the others have written before you start, and leave what you make for
them.

## Where results go

Write explanations, exercises and cheat sheets to `notes/`, one Markdown file
per topic. Explain from what the user already knows, keep examples small and
runnable, and link the primary docs for each idea.
